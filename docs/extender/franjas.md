# Franjas (v1, Y37): the band of the day, a hook for other features

`features/franjas` turns the zone's clock (`entorno` `hora`, in steps of 0.05 h) into one of four bands — `amanecer` (dawn), `dia` (day), `ocaso` (dusk), `noche` (night) — with whole numbers only, and announces each change. It reads `entorno` and never writes it; it never touches the simulation or the fingerprint.

- **Data**: `features/franjas/franjas.json` (`numinia-engine/franjas@1`): `desde` = the hour each band starts (house: 5 / 7 / 18 / 20; each a multiple of 0.05, in day order around the clock, no ties; `leerDesde` says the path and how to fix a mistake), `textos` = one block per language (`en` by default, `es` as a translation; same keys), `idioma` = the language a server says aloud. `crearFranjas({ desde, idioma, avisar })` overrides them per world; `avisar: false` keeps the state and the query but says nothing.
- **State**: one entry, `zona` (same key as entorno): `franja`, `siguiente`, `desde` (the hour the next band starts), `activa` (the day cycle runs), `texto` (the card sentence). Its card, «Time of day», is what screen readers and agents read. Nobody writes it but this feature.
- **When it speaks**: the event `franja` (`franja`, `anterior`, `texto`; text + sound `suave`, importance 1) is emitted exactly once per change, and only while the day cycle runs (`entorno.ciclo` > 0) and was already running at the previous look. Never at start-up, never when someone joins (they read the card), never without a cycle. Midnight is no special case (night goes on across 23.95 → 0).
- **The hook** (no import: a feature imports only `core`, `schema` and `feature`):
  - server: `api.listen("franjas", "franja", (m) => …)` for the change; `api.estadoDe("franjas").get("zona")?.franja` for now. When the event arrives the state already says the new band.
  - page: `api.estadoDe("franjas")` the same way, or `franjas.actual()` from `features/franjas/client.ts` in the composition root.
- **Verb**: `consultar` («ask the time of day»): the answer (`estado`) comes only to the asker. Any page, agent or screen reader gets the notice and the card from the server's catalog with no page part (the first-load budget has 83 B of room left: `features/cliente.ts` does not list `franjas`, like `sucesos` and `espacios`). `features/franjas/client.ts` (state read, `consultar()`, the «Time of day» button for touch and VR) is ready for a composition root that wants it.
- **Tests**: `test/franjas.test.ts` (12: all 480 steps covered with no gap or overlap, the reader, a whole day with one notice per change, midnight, no cycle, silent and Spanish worlds, `consultar`, no environment, a feature hooking on).
- **Not done yet**: a world's own `franjas.json` (today the house file, or `crearFranjas(...)` in code); per-preset hours; one sound per band (the engine has a closed list of sounds, `suave` for all until Y30).
