# server

`startServer()`: HTTP `/health` `/metrics` `/metrics.prom` `/sesiones` + `/a/<sha256>.<ext>` (H1, `activos.ts`: the house library `activos/` indexed by sha256 at start, uploads in ACTIVOS_DIR; a year of cache, any origin) + WebSocket on one port; the world's roles (H3: `roles.ts` = numinia.com's STD-051/052 rules, pure; `roles-mundo.ts` = one world's roles in a server-side feature «roles» with the chat orders /roles /dueño /dar /quitar /silenciar /echar /vetar /perdonar /solo-miembros; every permission check asks it; a visitor is «@todos», whose build-in-worlds is MOTOR_CONSTRUIR=todos; taken-out connections close with code 4003; H3b: `pase.ts` = numinia.com's Ed25519 world pass, MOTOR_PASE_CLAVE / MOTOR_PASE_MUNDO / MOTOR_PASE_ORG, a good pass replaces that person's roles), tick/runtime/host metrics, measuring bots, load swarm with reports, CPU bench, session log (T1: how each player entered, `sesiones.ts`; reader `npm run sesiones`), the features' saved data (S4, `datos.ts`: snapshot + journal per feature in DATOS_DIR).

- **World folder, page, status, image (motor en la flota, C1–C6):** `mundo-carpeta.ts` (MOTOR_MUNDO = the whole world: `datos/`, `aventura/` seeded once from `aventuras/ejemplo`, `entorno/`, `sesiones/`, `mundo.json`; keys MOTOR_SECRET|JWT_SECRET, MOTOR_ADMIN|ADMIN_CODE, else `claves.env` made once, 600, never printed), `pagina.ts` (the built page under WWW_DIR: no `..`, no dotfiles, no symlinks out; `index.html` no-cache, `assets/*` immutable, ETag/304), `GET /status` (`{uptime, conectados, commitHash, version}`, `version.ts`: `app/build.json` or env ENGINE_BUILD/ENGINE_COMMIT or git), `mundo-zip.ts` (`numinia-engine/mundo@2` + `mundo-extras.ts`: compose.yml, arrancar.sh, LEEME.txt; `@1` still read), `mundo-cli.ts` + `entrada.ts` (the image's entry: server, `copia`, `comprobar`, `importar`). Tested by `test/flota.test.ts`, `test/mundo-zip.test.ts`, `test/roles.test.ts`; the image by `Dockerfile` + `deploy/README.md`.
- **Does not:** Game logic; it only wires `instance` to the network.
- **Depends on:** core, schema, ecs, sim, net, instance, feature (rule: `tools/layers.json`); `main.ts` is a composition root and imports `features/servidor.ts`
- **Tested by:** `test/server.test.ts`, `test/measure.test.ts`, `test/sesiones.test.ts`, `test/datos.test.ts`, `test/objetos.test.ts`; load: `tools/swarm.sh 1000 30`; how to read the numbers: `docs/MEDIDAS.md`
- **Uploads (H9, `subidas.ts`):** `PUT /a/<sha256>.<ext>` with `Authorization: Bearer <guest token>` (I1) — only for who
  may build (401 no token, 403 no permission), kinds of `ficheros.ts` (415), caps per kind and in total (413, 507; `limits.json`),
  the server's own sha256 and a check of the bytes (422), stored once in `ACTIVOS_DIR` (default `DATOS_DIR/activos`) with who,
  when and the original name in `subidas.jsonl` (never served). `HEAD /a/…` answers like GET without a body; `OPTIONS` for
  CORS. Tested by `test/subidas.test.ts`, `tools/e2e-piernas/subir.mjs`, `tools/deploy-check.mjs`.
- **Main API:** `startServer`, `buildMetrics`, `toPrometheus`, `wsTransport`, `Hist`, `Runtime`, `PUERTAS`
